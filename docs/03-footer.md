# 푸터 사업자 정보

카드사는 **사업자등록증을 기준으로** 푸터를 대조합니다. 사업자등록증과 완전히 같지 않으면 카드사 심사가 반려됩니다. 공개 페이지와 로그인 화면을 포함한 모든 화면에 같은 푸터를 둡니다. 로그인해야 보이면 심사 담당자가 확인할 수 없습니다.

앱 서비스는 꼭 하단 푸터가 아니어도 되지만, 앱 안 어딘가에는 반드시 적어야 합니다.

## 표시 항목

| 항목 | 작성 기준 | 근거 |
| --- | --- | --- |
| 상호명 | 사업자등록증 상호와 동일 | 계약 심사 메일, 토스 체크리스트, 전자상거래법 제10조 |
| 대표자명 | 사업자등록증과 동일 | 계약 심사 메일, 토스 체크리스트, 전자상거래법 제10조 |
| 사업자등록번호 | `000-00-00000` | 계약 심사 메일, 토스 체크리스트, 전자상거래법 제10조 |
| 사업장 주소 | 사업자등록증과 동일. **층수와 동·호수까지** 기재. 불만 처리 주소가 다르면 함께 표기 | 계약 심사 메일, 토스 체크리스트, 전자상거래법 제10조 |
| 유선번호 | 070, 0505, 전국대표번호, 080, 휴대폰번호 가능 | 계약 심사 메일, 토스 체크리스트, 전자상거래법 제10조 |
| 이메일 | 실제로 수신되는 주소 | 토스 체크리스트, 전자상거래법 제10조 |
| 통신판매업 신고번호 | 신고 후 받은 번호. 아직 없으면 `신고중` | 토스 체크리스트 |
| 호스팅 서비스 제공자 | 호스팅 업체 상호 | 전자상거래법 시행령 |
| 이용약관 링크 | 별도 문서로 연결 | 전자상거래법 제10조 |
| 취소·환불 규정 링크 | 별도 문서로 연결 | 토스 체크리스트 |
| 개인정보처리방침 링크 | 별도 문서로 연결, 굵게 강조 | 개인정보 보호법 |

계약 심사 메일은 상호명, 대표자명, 사업자등록번호, 사업장 주소, 유선번호 다섯 항목을 **사업자등록증과 완전하게 일치**하도록 하단에 적으라고 요구합니다.

**템플릿 푸터는 현재 유선번호와 호스팅 서비스 제공자를 표시하지 않습니다.** 유선번호는 계약 심사 메일, 계약과정 FAQ, 결제경로 제작 가이드가 모두 필수로 요구하므로 심사 전에 [SiteFooter.tsx](../web/src/components/SiteFooter.tsx)의 `BUSINESS_ROWS`에 다음 행을 추가하세요. 값은 `config.ts`의 `company.tel`에 이미 있습니다.

```ts
{ label: '고객센터', value: company.tel, isEmail: false },
```

호스팅 서비스 제공자는 메일 항목에는 없지만 전자상거래법 시행령의 표시 사항입니다. 푸터에 둘지 법무 담당자에게 확인하세요. 지금은 개인정보처리방침의 위탁 업체 표에만 있습니다.

## 통신판매업 신고

- 신고번호가 없으면 **국민카드 심사가 제외**됩니다.
- 신고 중이어도 PG 계약과 다른 카드사 심사는 진행할 수 있습니다. 국민카드는 번호를 받은 뒤 심사받으면 됩니다.
- 간이과세자, 비영리기관, 공공기관은 없어도 됩니다.
- 번호를 받기 전에는 [config.ts](../web/src/config.ts)의 `mailOrderNumber` 를 `null` 로 두면 푸터에 `신고중`으로 표시됩니다. 표시만 바뀔 뿐 심사에서는 번호가 없는 것과 같으므로, 번호를 받는 즉시 넣으세요.

## 자주 틀리는 부분

- 주소를 건물명까지만 적음 → 층수와 동·호수까지 적으세요.
- 저작권 표기가 영문 브랜드명이고 상호명과 다름 → 다른 상호명이 적혀 있으면 반려될 수 있습니다. `© 2026 상호명` 으로 통일하세요.
- 사업장을 옮겼는데 등록증만 바꾸고 푸터는 그대로 → 둘 다 같은 날 바꾸세요.
- 약관, 환불, 개인정보 링크가 한 문서로 연결 → 각각 분리하세요.
- 링크를 눌렀더니 로그인 화면으로 이동 → 로그인 없이 열려야 합니다.
- 카드사 심사 중에 사업자정보나 전화번호를 고침 → 반려되고 심사를 처음부터 다시 받습니다. 심사가 끝날 때까지 바꾸지 마세요.

## 공정위 사업자정보 공개페이지

통신판매업자는 초기 화면에 공정위 사업자정보 공개페이지를 연결해야 한다는 지적이 공정위 심결에 반복해서 나옵니다. 적용 여부와 연결 주소를 법무 담당자에게 확인하세요.

## 그대로 쓸 수 있는 마크업

템플릿은 [SiteFooter.tsx](../web/src/components/SiteFooter.tsx)가 [config.ts](../web/src/config.ts)의 회사 정보로 푸터를 그립니다. 서버 렌더링을 쓰는 서비스는 아래 마크업을 HTML에 직접 넣어도 됩니다.

```html
<footer class="site-footer">
  <div class="site-footer-inner">
    <nav aria-label="약관 및 정책" class="footer-links">
      <a href="/policies/terms">이용약관</a>
      <a href="/policies/refund">취소·환불 규정</a>
      <a href="/policies/privacy"><strong>개인정보처리방침</strong></a>
    </nav>
    <dl class="footer-business">
      <div><dt>상호명</dt><dd>주식회사 예시</dd></div>
      <div><dt>대표자명</dt><dd>홍길동</dd></div>
      <div><dt>사업자등록번호</dt><dd>000-00-00000</dd></div>
      <div><dt>통신판매업 신고번호</dt><dd>제0000-000000-00-00000호</dd></div>
      <div><dt>사업장 주소</dt><dd>서울특별시 ...</dd></div>
      <div><dt>이메일</dt><dd><a href="mailto:help@example.com">help@example.com</a></dd></div>
    </dl>
    <p class="footer-copyright">© 2026 주식회사 예시. All rights reserved.</p>
  </div>
</footer>
```
