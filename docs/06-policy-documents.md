# 정책 문서

토스는 환불 정책을 홈페이지에 적도록 요구합니다. 이용약관과 개인정보처리방침은 관련 법령에 따라 필요합니다.

정책 초안은 [web/src/pages/policies/](../web/src/pages/policies/)에 있습니다. **법률 자문이 아닙니다. 자사 서비스에 맞게 고치고 법무 검토를 받으세요.**

## 준비할 문서

| 문서 | 필수 내용 | 게시 위치 |
| --- | --- | --- |
| [이용약관](../web/src/pages/policies/TermsPage.tsx) | 서비스 내용, 이용료, 자동결제, 결제 실패, 해지 | 푸터 링크, 동의 화면 |
| [취소·환불 규정](../web/src/pages/policies/RefundPage.tsx) | 환불 기준, 산식, 절차, 기간, 연락처 | 푸터 링크, 랜딩 요약, 결제 직전 요약 |
| [개인정보처리방침](../web/src/pages/policies/PrivacyPage.tsx) | 처리 항목, 목적, 기간, 위탁, 권리, 보호책임자 | 푸터 링크 |

## 게시 규칙

- 문서마다 **별도 URL**로 분리합니다. 한 문서로 몰아 넣으면 심사 담당자가 환불 정책을 찾지 못합니다.
- 로그인 없이 열려야 합니다.
- `준비 중`, `확정 전`, `추후 안내` 같은 문구를 남기지 않습니다.
- 시행일과 버전을 표시합니다.
- 환불 정책 주소는 계약 심사 회신에 적으므로 회신한 뒤에는 바꾸지 않습니다.
- 결제 1회당 서비스 제공기간을 상품 페이지와 약관에 명확히 적습니다. 12개월을 넘으면 입점할 수 없습니다.
- 개정하면 이전 버전을 보관합니다. 동의 기록의 `termsVersion` 이 어느 문서를 가리키는지 알아야 합니다.

## 환불 정책 요건

토스페이먼츠 계약과정 FAQ가 제시하는 요건입니다. 이보다 불리한 조건은 심사에서 문제가 될 수 있습니다.

- 구매일로부터 7일, 또는 공급이 시작된 날로부터 7일 중 **더 늦은 날까지** 환불할 수 있어야 합니다.
- 공급 뒤 파손, 훼손, 사용으로 가치가 줄어 다시 팔 수 없는 경우는 예외입니다.
- 용역이나 콘텐츠 같은 무형재화는 **제공이 시작되지 않은 부분을 일할 계산으로 환불**할 수 있어야 합니다.

템플릿의 즉시 해지는 남은 기간을 일할 계산해 전액 환불하고, 미납금과 아직 청구하지 않은 추가 사용료만 뺍니다. 위약금을 두려면 법무 검토와 계약 담당자 확인을 먼저 받으세요.

## 자사 조건으로 바꿀 값

금액과 회사 정보는 [config.ts](../web/src/config.ts)에서 바꾸면 정책 문서에 자동으로 반영됩니다. 환불 계산 예시는 [refund.ts](../web/src/billing/refund.ts)로 계산합니다. 다음은 문장을 직접 고칩니다.

| 항목 | 템플릿 기본값 | 정해야 할 것 |
| --- | --- | --- |
| 청약 철회 | 7일 이내, 이용 내역 없으면 전액 | 소비자 대상이면 법정 기준 이상으로 |
| 즉시 해지 환불 | 남은 기간 일할 금액 − 미납금 − 추가 사용료 | 공제 항목. 위약금은 [요건](#환불-정책-요건) 확인 후 |
| 기간 종료 해지 | 환불 없음, 마지막 날까지 이용 | 그대로 쓸지 |
| 재시도 일정 | D1, D3, D7 | 횟수와 간격 |
| 미납 시 제한 시점 | D7 이후 | 재시도 기간에 서비스를 유지할지 |
| 환불 처리 기간 | 확정 후 5영업일 이내 | 운영 가능한 기간 |
| 수집 항목, 위탁 업체 | 예시 | 실제 수집 항목과 업체 |

## 약관·화면·서버 대조표

**세 곳이 어긋나면 분쟁의 원인이 되고 심사에서도 지적받을 수 있습니다.** 값을 바꾸면 이 표의 모든 곳을 함께 바꾸세요.

| 항목 | 약관·정책 | 화면 | 서버 |
| --- | --- | --- | --- |
| 월 구독료 | 이용약관 제7조 | 랜딩, 결제, 구독 관리 | 청구 금액 |
| 추가 사용 단가 | 이용약관 제7조 | 랜딩, 결제, 동의 | 갱신 계산식 |
| 추가 사용료 상한 | 이용약관 제7조에 추가 | 랜딩, 동의 | 갱신 청구 상한 = 계약 심사에 회신한 단건 최고가 |
| 서비스 제공기간 | 이용약관 제2조 | 랜딩, 결제 | 계약 심사에 회신한 최대 제공기간 |
| 결제일 규칙 | 이용약관 제9조 | 동의, 결제 | 다음 결제일 계산 |
| 재시도 일정 | 이용약관 제11조, 환불 규정 7항 | 동의, 결제, 미납 안내 | 재시도 스케줄 |
| 서비스 제한 시점 | 이용약관 제11조 | 동의, 미납 안내 | 실제 접근 차단 시점 |
| 해지 적용 시점 | 이용약관 제13조 | 동의, 해지 대화상자 | `cancelAt` 처리 |
| 환불 기준 | 환불 규정 2~3항 | 랜딩, 결제 요약 | 취소 금액 계산 |
| 결제 통지 | 이용약관 제9조, 동의 항목 | 동의 | **실제 메일 발송** |
| 동의 버전 | `policy.termsVersion` | 동의 | 동의 기록 |

자주 놓치는 항목입니다.

- **결제 통지**: 약관에 이메일로 알린다고 적었다면 서버에 메일 발송을 구현해야 합니다.
- **환불**: 즉시 해지 환불을 약속했다면 토스 취소 API나 상점관리자로 처리할 절차가 있어야 합니다.
- **유예 기간**: 약관은 7일 유지인데 서버가 결제일에 바로 막으면 약관 위반입니다.

## 관련 법령

조문은 개정될 수 있으니 [국가법령정보센터](https://www.law.go.kr)에서 현행 내용을 확인하세요.

| 주제 | 내용 | 근거 |
| --- | --- | --- |
| 사이버몰 표시 사항 | 상호, 대표자, 주소, 연락처, 사업자등록번호, 이용약관, 호스팅 제공자 | 전자상거래법 제10조, 시행령 |
| 청약 철회 | 소비자는 원칙적으로 7일 이내 철회 가능. 디지털 콘텐츠는 제공 개시 후 제한될 수 있으나 사전 조치가 필요 | 전자상거래법 제17조 |
| 정기결제 증액, 유료 전환 | 변경 전 30일 이내에 동의를 받고 철회 조건과 방법을 고지 | 전자상거래법 제13조 제6항, 시행령 제20조의2 (2025-02-14 시행) |
| 다크패턴 | 숨은 갱신, 순차 공개 가격, 취소·탈퇴 방해 등 금지 | 전자상거래법 |
| 개인정보처리방침 | 공개 의무와 필수 기재 사항 | 개인정보 보호법 제30조 |
| 거래 기록 보존 | 계약·결제 기록 5년, 분쟁 기록 3년 | 전자상거래법 시행령 |

B2B 전용 서비스도 소비자에 해당하는 이용자가 있으면 강행규정이 우선합니다. 무료 체험을 유료로 전환한다면 최초 계약 때 동의를 받았더라도 전환 전 30일 이내에 다시 동의를 받아야 합니다.
